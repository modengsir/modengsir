# Keke GitHub Profile Starter

一个面向新手的 GitHub 个人主页模板：包含一句话介绍、联系方式、可编辑的 X 名片和产品作品集。

不需要会写代码。填写一份个人资料，把仓库自带的提示词交给 Codex 等 AI 编程助手，就能生成自己的主页。

## 你会得到什么

- 一句话 **About Me** 英文介绍
- 邮箱、小红书和 X 联系方式
- 一张紫蓝色科技极简 X 名片
- 清晰的 **My Products** 作品表格
- 首屏优先的紧凑排版

效果参考：[Keke 的 GitHub 主页](https://github.com/sunkeke-ai)。

## 5 分钟复刻

1. 点击仓库上方的 **Use this template** → **Create a new repository**。
2. 新仓库名称必须和你的 GitHub 用户名完全相同，并选择 **Public**。
3. 打开 [`PROFILE_INFO.md`](./PROFILE_INFO.md)，把示例信息换成你的资料。
4. 复制 [`BUILD_MY_PROFILE.md`](./BUILD_MY_PROFILE.md) 里的提示词，交给 Codex 或其他 AI 编程助手。
5. 确认 AI 生成的 `README.md` 和 `x-card.svg`，提交后主页会自动更新。

完整步骤和常见问题请看 [`QUICK_START.md`](./QUICK_START.md)。

## 文件说明

| 文件 | 用途 |
|---|---|
| `PROFILE_INFO.md` | 唯一需要填写的个人资料表 |
| `BUILD_MY_PROFILE.md` | 可以直接复制给 AI 的提示词 |
| `README.template.md` | AI 使用的主页结构模板 |
| `x-card.svg` | 可修改文字和配色的 X 名片 |
| `QUICK_START.md` | 零基础完整教程 |

## 后续自定义

你可以继续修改配色、文案、联系方式或产品数量。模板刻意保持简洁，让访客打开主页后不用长距离滚动，就能快速明白你是谁、在做什么。
